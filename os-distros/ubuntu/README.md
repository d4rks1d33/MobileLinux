# ubuntu (planned)

This is a **planned** distribution: the descriptor (`distro.yaml`) records the
intended base, package manager, builder and kernel flavor, but no build backend
is registered yet and `mobilelinux build --distro ubuntu` will report it as unknown
until one is added.

See [../README.md](../README.md) for the distro roadmap and
[../../docs/os-distros.md](../../docs/os-distros.md) for how to add a distro
backend.
